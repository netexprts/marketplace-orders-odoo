# Marketplace Orders → Odoo

أداة HTML واحدة (بدون أي سيرفر أو تثبيت) بتحوّل تقارير مبيعات NOON (FBN وFBP)، Amazon، وTrendyol إلى ملف Excel جاهز للاستيراد المباشر في Odoo.

## الاستخدام
افتح ملف `MP odoo orders.html` في أي متصفح، اختار التاب بتاع المنصة، ارفع تقرير المبيعات (CSV/XLSX)، ونزّل ملف الإكسل الجاهز للاستيراد في Odoo.

## التفاصيل الكاملة
كل تفاصيل ربط الأعمدة، منطق التجميع، وتوحيد حالة الشحن موثقة في [`PROJECT_NOTES.md`](./PROJECT_NOTES.md).

## عينات بيانات
مجلد `data/` فيه عينة تقرير من كل منصة (NOON FBN، NOON FBP، Amazon، Trendyol) للاختبار.
